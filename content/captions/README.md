# Caption & hashtag template

Use this when pasting into Instagram after `content/exports/<slug>_reel.mp4` is ready.

## Template

```text
[HOOK LINE — same as on-screen first 3s]

[1–2 sentence myth beat / emotional punch]

[CTA — save / comment / share / Part 2 ask]

.
.
.

[3–5 niche tags]
[3–5 broad discovery tags]
[1–2 AI / Reel format tags]
```

## Example (Hanuman)

```text
He didn’t need wings. He needed faith.

Hanuman’s leap isn’t just strength — it’s devotion mid-air.

Double-tap if Bajrangbali is your strength. Comment 🔥 for Part 2: burning Lanka.

.
.
.

#Hanuman #Bajrangbali #Ramayana
#HinduMythology #IndianGods #MythologyReels
#AIArt #AIReels
```

## Rules of thumb

- First line = hook (matches video text overlay).
- CTA in the first 125 characters when possible (before “…more”).
- Mix Sanskrit/English names for search (#Hanuman + #Bajrangbali).
- Always include one clear ask: save, comment emoji, or “Part 2”.
- Avoid banned/spammy tag stuffing; 8–12 tags is enough.
- Manual upload only — paste caption by hand (Ceo / Jagadeeswar).
